# Бурмалдец (он же Чекунец)

Личный голосовой ИИ-ассистент для **Android** и **Windows**. Зовёте по имени, «Бурмалдец» или «Чекунец», или нажимаете на плавающий шар. Он отвечает голосом, ищет в интернете, ставит напоминания и таймеры, включает музыку, смотрит на экран, ведёт заметки и расходы, а на телефоне ещё звонит и управляет приложениями.

**Свой ключ — любой ИИ.** При первом запуске выбираете провайдера и вставляете свой API-ключ:

| Провайдер | Что умеет |
|---|---|
| Google Gemini | бесплатный ключ, живой голос, зрение, распознавание речи |
| OpenAI | голос, зрение, Whisper |
| Anthropic Claude | — |
| OpenRouter | сотни моделей, есть бесплатные |
| Groq | очень быстро, бесплатный тариф, Whisper |
| DeepSeek, Mistral, xAI Grok | — |
| Свой сервер | Ollama, LM Studio или любой OpenAI-совместимый адрес |

Модель выбирается из списка, который приходит прямо от провайдера по вашему ключу. Ключи и память хранятся только на устройстве. Запросы идут напрямую к выбранному провайдеру, без посредников.

## Возможности

- **Слово-активатор офлайн.** Vosk на самом устройстве слышит «Бурмалдец» и «Чекунец»; звук никуда не отправляется. Vosk слышит эти слова как «бур молодец» и «чеку нет», и правило проверено на записях: обычная речь его не будит.
- **Плавающий шар поверх всех приложений** (Android): нажали — открывается «шторка» поверх текущего экрана; закончили говорить — она сама прячется.
- **Шар на рабочем столе** (Windows): панель рядом с шаром, значок в трее, горячая клавиша `Ctrl+Alt+Пробел`, автозапуск.
- **Навыки без ИИ.** Отвечают мгновенно, даже когда ИИ перегружен: погода, курсы, новости, заметки, расходы, напоминания, будильник, счёт, сводка дня.
- **Режим повара** по команде «режим повара»: рецепты для мультипечи ГрандШеф, готовка по шагам, холодильник.
- **Голос:** Gemini, OpenAI, бесплатный Microsoft Edge (на ПК) или голос устройства.

## Сборка

```bash
python scripts/vosk.py          # модель распознавания (один раз)
python scripts/recipes.py       # каталог рецептов для режима повара (если есть соседний проект MyGrandChef)

cd web && npm install && npm run build          # веб-ядро (React + Vite)

# Android
python android/sync_web.py
cd android && ./gradlew assembleRelease         # подпись: android/keystore.properties (не в git)

# Windows
cd desktop && npm install && npm run dist       # установщик в desktop/release
```

Структура:

- `web/src/shef/` — мозг и интерфейс: `agent.ts` (ИИ и инструменты), `llm.ts` (переводчики Gemini/OpenAI/Anthropic), `ai.ts` (провайдеры), `skills.ts` (навыки без ИИ).
- `android/` — оболочка на Kotlin: `WakeService` (слух), `Bubble` (плавающий шар), `ShefAccess` (управление экраном), `Macros` (сценарии).
- `desktop/` — Electron: `main.js` (окна, трей, мост), `pc.js` (действия Windows), `orb.html` (шар).
